# Tello brand kit

Mark: the "Aurora T". A glass-edged T filled with slowly drifting light, on a black tile. It is alive, like Tello.
The animated SVG moves in browsers; the PNG files use a still frame.

## Colors (approved by eli, 2026-10-13)
- Black `#050505` / `#141414` (tile and backgrounds)
- White `#ffffff` (text on dark, highlights)
- Gray `#8a8f93` (secondary text, glass)
- Yellow `#ffd23f` (".live" and buttons)
- Lime `#b6f04a`, Green `#46d39a`, Deep green `#1fa070` (the light inside the T)

## Files
- `tello-mark.svg`: animated mark on a black tile (website header, favicon)
- `tello-mark-smoke.svg`: same mark with slow smoke rising off the T (large placements)
- `tello-hero.svg`: big tile-free version where the smoke rises into the page (home page hero)
- `tello-mark-light.svg`: animated mark on a white tile, for light backgrounds
- `tello-mark-static.svg` / `tello-mark-static-light.svg`: still versions for email, print and apps that cannot animate
- `tello-mark-bare.svg`: still mark without the tile
- `tello-mark-mono-dark.svg` / `tello-mark-mono-light.svg`: one-color T for stamps, print and embroidery
- `tello-logo-horizontal-on-dark.svg` / `-on-light.svg`: mark plus "tello.live"
- `tello-logo-stacked-on-dark.svg` / `-on-light.svg`: mark above "tello.live"
- `tello-avatar-1024.png`: profile picture for every social network
- `tello-icon-1024/512/192/48/32.png`, `tello-apple-touch-180.png`: app and website icons
- `tello-x-header-1500x500.png`, `tello-linkedin-banner-1584x396.png`, `tello-facebook-cover-1640x624.png`, `tello-youtube-banner-2560x1440.png`: cover images
- `tello-og-1200x630.png`: link share preview
- `tello-post-square-1080.png`: square post for Instagram and Facebook

## Rules
- The name is "Tello". The site is written tello.live, with ".live" in yellow.
- Keep clear space around the mark equal to the width of the T's stem.
- Do not stretch or recolor the mark, and do not add outlines. Never put it on a busy photo without its tile.
- Use the still versions wherever motion is distracting (print, email, tiny sizes).
- The wordmark in the SVG files is converted to outlines from Inter ExtraBold, so no font is needed.
